# image-editor

Учебный проект по курсу "Технологии компьютерной графики". Браузерный редактор изображений на React + TypeScript.

Хостинг: https://bekmuratov-d.github.io/image-editor/

## Лаба 1 — цифровое представление изображения

Реализовано:
- загрузка и отрисовка изображений на `<canvas>`;
- поддержка PNG и JPG (через встроенные возможности браузера);
- поддержка собственного формата **GB7** — кодек написан руками, без библиотек;
- статус-бар с шириной, высотой и глубиной цвета изображения;
- скачивание изображения в PNG, JPG или GB7;
- загрузка файла через кнопку или drag-and-drop;
- адаптивная вёрстка.

## Лаба 2 — цветовые каналы и пипетка

Реализовано:
- панель каналов справа: превью каждого канала изображения в оттенках серого (grayscale / grayscale+alpha / RGB / RGB+alpha — в зависимости от того, что реально есть у загруженной картинки);
- клик по превью включает/выключает канал, изменение сразу отражается на главном canvas (не трогая исходные данные изображения — для отображения всегда строится новый массив пикселей);
- если оставить включённой только альфу — видно чёрно-белую маску прозрачности (белое = видно, чёрное = прозрачно);
- инструмент "Пипетка": клик по изображению показывает координаты пикселя, RGB (0-255) и цвет в пространстве CIE Lab;
- пипетка всегда читает исходный цвет пикселя, независимо от того, какие каналы временно скрыты в панели.

Классификация канала для PNG определяется по байту color type в заголовке PNG (IHDR) — не любой PNG имеет альфа-канал, и не любой PNG цветной; JPG всегда RGB без альфы; GB7 всегда в оттенках серого (с альфой при наличии маски).

## Лаба 3 — гистограмма и инструмент "Уровни"

Реализовано:
- гистограмма изображения: композитная (по светлоте, формула `0.299R+0.587G+0.114B`) или по конкретному каналу (R/G/B/Alpha), с переключением между линейным и логарифмическим масштабом;
- инструмент "Уровни" в диалоговом окне (`<dialog>`): три маркера — чёрная точка, белая точка, гамма (средние тона), с ограничениями (чёрная не может зайти за белую и обратно, маркер гаммы всегда между ними);
- настройки уровней применяются к Master (все RGB-каналы) или к отдельному каналу, включая Alpha; все 5 наборов настроек (Master + R/G/B/Alpha) хранятся одновременно и не теряются при переключении между ними;
- живой предпросмотр (включён по умолчанию) — изменения сразу видны на главном холсте; выключение чекбокса моментально возвращает картинку к состоянию до открытия диалога;
- кнопки "Сброс" (сбрасывает все настройки, не закрывая диалог), "Отмена" (закрывает диалог без изменений) и "Применить" (навсегда переносит правку в данные изображения);
- коррекция реализована через таблицы подстановки (LUT) на 256 значений — пересчитывается один раз при изменении настроек, а не на каждый пиксель;
- перетаскивание маркеров троттлится через `requestAnimationFrame`, чтобы не пересчитывать картинку чаще одного раза за кадр.

Инструмент "Уровни" — первая функция, которая по-настоящему изменяет данные изображения (а не просто по-другому их показывает, как было с каналами в лабе 2).

## Формат GB7

GrayBit-7 — 7-битный формат в оттенках серого с опциональной бинарной маской (8-й бит). Подробное описание структуры файла — в коде декодера/энкодера: [gb7Decoder.ts](src/core/codecs/gb7/gb7Decoder.ts), [gb7Encoder.ts](src/core/codecs/gb7/gb7Encoder.ts).

Так как формат хранит только 7 бит на пиксель, цикл загрузка → сохранение → загрузка не даёт побитово идентичный результат (теряется младший бит серого), это ожидаемое поведение формата, а не ошибка. Сохранение цветного изображения (PNG/JPG) в GB7 переводит его в оттенки серого — формат не умеет хранить цвет.
